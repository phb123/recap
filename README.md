# Recap

Recap writes a one-page summary of a project from your chats with coding agents: Claude Code, Codex, Cursor, OpenCode, Gemini CLI, Factory Droid, and Pi. Recent work gets the most detail.

## Just paste this to your favorite coding agent

```text
This repository contains an agent skill:
https://github.com/phb123/recap

Install plugins/recap/skills/catch-up from this repository as a skill named catch-up in your skills directory (for example $CODEX_HOME/skills/catch-up or ~/.claude/skills/catch-up).
```
