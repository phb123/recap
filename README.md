# Recap

Recap is a native Codex plugin that turns recent local Codex session traces into a clear handover of a project's direction, current state, and next steps.

## Just paste this to your favorite coding agent

```text
This repository contains a Codex skill:
https://github.com/phb123/recap

Install plugins/recap/skills/catch-up from this repository as $CODEX_HOME/skills/catch-up.
```
